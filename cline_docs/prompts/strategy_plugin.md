# 策略阶段插件

本插件定义了CRCT系统的策略阶段的操作流程和规则。

## I. 策略阶段概述

策略阶段是CRCT系统的规划阶段，负责：

1. **任务分解**：将复杂任务分解为可管理的子任务
2. **指令文件创建**：为每个子任务创建详细的指令文件
3. **依赖关系规划**：确定任务之间的依赖关系
4. **优先级设置**：为子任务设置执行优先级

## II. 策略阶段工作流程

1. **读取`.clinerules`**：确定当前阶段和上一次操作
2. **加载上下文**：读取`system_manifest.md`和`activeContext.md`
3. **任务分析**：分析当前任务，确定范围和目标
4. **递归分解**：将任务分解为子任务，创建层次结构
5. **创建指令文件**：为每个子任务创建详细的指令文件
6. **依赖关系分析**：确定子任务之间的依赖关系
7. **更新系统状态**：遵循强制更新协议(MUP)更新系统状态
8. **准备执行阶段**：完成所有策略任务后，准备进入执行阶段

## III. 任务分解和指令文件创建

### 任务分解原则

1. **单一责任原则**：每个子任务应专注于单一功能或目标
2. **明确边界**：子任务之间应有明确的边界和接口
3. **可测试性**：每个子任务应可独立测试和验证
4. **合理粒度**：子任务应足够小以便于管理，但不应过于细碎
5. **依赖最小化**：尽量减少子任务之间的依赖关系

### 指令文件结构

指令文件应包含以下部分：

1. **任务标题**：简明描述任务目标
2. **背景**：提供任务的上下文和背景信息
3. **目标**：明确定义任务的具体目标和成功标准
4. **依赖关系**：列出任务的前置依赖和后置依赖
5. **步骤**：详细的任务执行步骤
6. **验证**：验证任务完成的方法和标准
7. **注意事项**：执行任务时需要注意的事项和潜在问题

### 创建指令文件的步骤

1. **使用模板**：使用`cline_docs/templates/task_instruction_template.md`作为基础
2. **填充内容**：根据任务分析填充各个部分
3. **验证完整性**：确保所有必要的部分都已填充
4. **保存文件**：将指令文件保存到适当的位置

## IV. 依赖关系规划

依赖关系规划是策略阶段的关键部分，用于确保任务按正确的顺序执行。

### 依赖关系类型

1. **前置依赖**：必须在当前任务之前完成的任务
2. **后置依赖**：依赖于当前任务的任务
3. **并行任务**：可以与当前任务并行执行的任务

### 依赖关系规划步骤

1. **识别依赖**：分析任务，识别其依赖关系
2. **记录依赖**：在指令文件的依赖关系部分记录依赖
3. **验证依赖**：确保依赖关系是合理和一致的
4. **更新跟踪器**：使用`dependency_processor.py`更新依赖关系跟踪器

## V. 策略阶段的强制更新协议(MUP)

除了核心MUP步骤外，策略阶段还需要执行以下特定步骤：

1. **更新`.clinerules`**：
   - 更新`[LAST_ACTION_STATE]`部分
   - 添加到`[LEARNING_JOURNAL]`部分

2. **更新`activeContext.md`**：
   - 记录当前策略操作的状态
   - 记录已创建的指令文件
   - 记录任务分解和依赖关系规划的结果

3. **更新`system_manifest.md`**：
   - 如果需要，更新项目结构和模块关系

4. **更新模块文档**：
   - 如果需要，更新相关模块的文档

## VI. 阶段转换检查清单

在从策略阶段转换到执行阶段之前，必须完成以下检查：

1. **指令文件检查**：
   - 所有指令文件都已创建并包含必要的内容
   - 指令文件中的"步骤"和"依赖关系"部分已完成

2. **依赖关系检查**：
   - 所有任务的依赖关系都已明确定义
   - 依赖关系是一致和合理的

3. **系统状态检查**：
   - 已执行强制更新协议(MUP)
   - `.clinerules`中的`next_phase`设置为"Execution"

只有在完成所有这些检查后，才能进入执行阶段。

## VII. 实现计划创建

实现计划是HDTA的第三层，用于详细描述模块内的特定实现。

### 实现计划结构

实现计划应包含以下部分：

1. **标题**：实现的名称
2. **概述**：实现的简要描述
3. **目标**：实现的具体目标
4. **设计决策**：关键设计决策和理由
5. **组件**：实现的主要组件
6. **接口**：组件之间的接口
7. **依赖关系**：实现的依赖关系
8. **测试策略**：测试实现的方法

### 创建实现计划的步骤

1. **使用模板**：使用`cline_docs/templates/implementation_plan_template.md`作为基础
2. **填充内容**：根据实现分析填充各个部分
3. **验证完整性**：确保所有必要的部分都已填充
4. **保存文件**：将实现计划保存到适当的位置
