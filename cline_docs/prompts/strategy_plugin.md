# Strategy 阶段插件

本插件提供了Strategy阶段的详细指导，包括任务分解、指令文件创建和优先级排序。

## I. Strategy阶段概述

Strategy阶段负责：
1. 任务分解
2. 指令文件创建
3. 依赖关系分析
4. 优先级排序
5. 实施计划制定

## II. 任务分解流程

1. 分析用户任务
2. 将任务分解为小的、可管理的子任务
3. 组织子任务的层次结构
4. 确定子任务之间的依赖关系

## III. 指令文件创建指南

为每个子任务创建指令文件，包括：
1. 任务描述
2. 步骤
3. 依赖关系
4. 预期输出
5. 验证标准

## IV. 依赖关系分析

分析子任务之间的依赖关系：
1. 上下文依赖
2. 任务依赖
3. 资源依赖

## V. 优先级排序

根据以下因素对子任务进行优先级排序：
1. 依赖关系
2. 重要性
3. 紧急性
4. 复杂性

## VI. 实施计划制定

制定详细的实施计划，包括：
1. 执行顺序
2. 时间估计
3. 资源分配
4. 风险评估

## VII. 阶段转换检查清单

在从Strategy阶段转换到Execution阶段之前，确认：
1. 指令文件包含完整的"步骤"和"依赖关系"部分
2. 子任务之间的依赖关系已明确定义
3. 实施计划已制定
