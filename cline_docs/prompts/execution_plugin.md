# Execution 阶段插件

本插件提供了Execution阶段的详细指导，包括任务执行、代码/文件修改和结果验证。

## I. Execution阶段概述

Execution阶段负责：
1. 任务执行
2. 代码/文件修改
3. 结果验证
4. 错误处理
5. 文档更新

## II. 任务执行流程

1. 读取指令文件
2. 验证依赖关系是否满足
3. 执行步骤
4. 记录结果
5. 更新状态

## III. 代码/文件修改指南

修改代码/文件时：
1. 在修改前验证文件系统状态
2. 增量执行修改
3. 记录修改内容
4. 验证修改结果

## IV. 结果验证

验证执行结果：
1. 检查预期输出
2. 运行测试（如果适用）
3. 验证功能
4. 检查边缘情况

## V. 错误处理

处理执行过程中的错误：
1. 记录错误信息
2. 分析错误原因
3. 制定解决方案
4. 重试或回滚

## VI. 文档更新

更新相关文档：
1. 更新指令文件状态
2. 更新依赖跟踪器
3. 更新`activeContext.md`
4. 更新`changelog.md`
5. 更新`.clinerules`

## VII. 强制更新协议（MUP）

每次状态变更操作后立即执行：
1. 更新`activeContext.md`
2. 更新`changelog.md`
3. 更新`.clinerules`
4. 验证更新的一致性
5. 更新相关的HDTA文件
